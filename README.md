# 峠 Touge Drift & Dash 🏎️💨

スマホ操作に特化した見下ろし型峠レース＆タイムアタックゲームです。

## 特徴
- **操作系**:
  - 車両前方タップで急加速ダッシュ！
  - スライド（なぞり）でその軌道へリアを流すドリフト！
  - 車両から離れた画面端のスライドで先読みカメラ移動
- **ゲーム性**:
  - 直線はダッシュ連打が最速
  - 壁や崖に衝突せずに走るとコンボメーターが溜まり、ダッシュ速度がLv.1〜MAXまで進化
  - ガードレール衝突（跳ね返り＆コンボリセット）
  - 崖ゾーン（コースアウトで奈落へ落下＆タイムロス）
  - タイムアタック＆自己ベスト記録（LocalStorage）
- **完全自己完結**:
  - 単一HTMLファイル（外部画像・音声アセット通信不要、Web Audio APIによるシンセ効果音）
